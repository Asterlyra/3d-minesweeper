# 三维扫雷

在三维网格中揭开安全格并标记地雷。浏览器需要 WebGL；页面通过 CDN 加载 Three.js，首次使用需要联网。

运行：在本目录执行 `python3 -m http.server 8000`，打开 <http://localhost:8000/>。

## 第三方依赖

本游戏通过 CDN 引用 [Three.js 0.166.1](https://github.com/mrdoob/three.js/tree/r166)，依赖使用 [MIT 许可证](https://github.com/mrdoob/three.js/blob/r166/LICENSE)。
